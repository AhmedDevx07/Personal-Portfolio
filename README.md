## 📖 About

This repository contains the source code for my personal portfolio website, built to showcase my projects, skills, and professional journey as a **Full Stack Developer** specializing in the **MERN stack** and modern **React ecosystem**.

🔗 **Live:** [ahmeddevx07.vercel.app](https://ahmeddevx07.vercel.app/)

---

## ✨ Key Features

- 🎨 **Modern UI/UX** — Sleek aesthetics, custom glows, and responsive grid patterns.
- 🎬 **Fluid Animations** — Smooth scrolling, scroll-spy navigation, and engaging micro-interactions powered by Framer Motion and native CSS animations.
- ⚡ **Optimized Performance** — Built on Next.js App Router, ensuring lightning-fast load times with Turbopack and `next/image` optimization.
- 📱 **Fully Responsive** — Flawless experience across mobile, tablet, and desktop viewports using Tailwind CSS.
- 📩 **Working Contact Form** — Integrated with EmailJS for seamless direct communication.
- ♿ **Accessible & SEO Optimized** — Screen-reader friendly with semantic HTML, appropriate aria-labels, and advanced OpenGraph metadata.
