## 📖 About

This repository contains the source code for my personal portfolio website. It showcases my full-stack projects, core technical proficiencies, and journey as a **Full Stack Developer** specializing in the **MERN Stack**, **Next.js**, and modern **AI Integrations**.

## ✨ Key Features

- 🎨 **Modern Dark Aesthetic** — Sleek UI with custom ambient glows, glassmorphism, and responsive layout.
- 🎬 **Fluid Animations** — Micro-interactions, custom scroll-spy navigation, and entrance effects via **Framer Motion**.
- ⚡ **Cutting-Edge Tech Stack** — Built on **Next.js 16 (App Router)** and **React 19**, compiled with **Turbopack**.
- 📱 **Fully Responsive** — Mobile-first, responsive layouts tailored for all screen sizes with **Tailwind CSS v4**.
- 📩 **Interactive Contact System** — Contact form integration powered by **EmailJS** with one-click email copying.
- ♿ **SEO & Performance Tuned** — Metadata configuration for rich social link previews and semantic accessibility.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### Prerequisites
- **Node.js** (v18.18.0 or newer recommended)
- **npm**, **yarn**, or **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AhmedDevx07/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

### Build for Production

```bash
npm run build
npm run start
```
